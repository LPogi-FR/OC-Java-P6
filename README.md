## Prérequis

### Java
Installer java version 17 du jdk. La suite du démarrage du projet suppose que vous ayez des notions en java et que vous soyez capable de démarrer un projet avec un IDE.

### Spring
Le framework  utilisé est Springboot sur la version 3.2.0

### Maven
La version utilisé lors du développement du projet est la version 3.9.15

### Base de donnée MySQL
La version utilisé lors du développement du projet est la version 8.0.33
Le fichier data.sql permet d'alimenter la DB au démarage de l'application.

### IDE (Environnement de développent intégré)
Enfin, vous devez avoir un IDE, j'utilise dans mon cas Intellij.

## Test
````bash
mvn clean verify
````
## Run
````bash
mvn spring-boot:run
````


### Contexte du projet
Ce projet a pour but d'implémenter un service d'envoi d'argent entre amis.
